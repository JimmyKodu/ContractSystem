## 合同审批流程图

### 公司模板流程

```
     ┌──────────┐
     │ 销售员   │
     │ 创建合同  │
     └────┬─────┘
          │
          ↓
     ┌──────────┐
     │ 销售经理  │  ←─── templateType = 0
     │   审批    │       (公司模板)
     └────┬─────┘
          │ 批准
          ↓
     ┌──────────┐
     │ 销售总监  │
     │   审批    │
     └────┬─────┘
          │ 批准
          ↓
     ┌──────────┐
     │  盖章人   │
     │   盖章    │
     └────┬─────┘
          │
          ↓
     ┌──────────┐
     │ 合同完成  │
     │ (已盖章)  │
     └──────────┘
```

### 客户模板流程

```
     ┌──────────┐
     │ 销售员   │
     │ 创建合同  │
     └────┬─────┘
          │
          ↓
     ┌──────────┐
     │ 法务部门  │  ←─── templateType = 1
     │ 法律审核  │       (客户模板)
     └────┬─────┘
          │ 批准
          ↓
     ┌──────────┐
     │ 销售经理  │
     │   审批    │
     └────┬─────┘
          │ 批准
          ↓
     ┌──────────┐
     │ 销售总监  │
     │   审批    │
     └────┬─────┘
          │ 批准
          ↓
     ┌──────────┐
     │  盖章人   │
     │   盖章    │
     └────┬─────┘
          │
          ↓
     ┌──────────┐
     │ 合同完成  │
     │ (已盖章)  │
     └──────────┘
```

## 合同状态转换图

```
                     Draft (草稿)
                         │
        ┌────────────────┴────────────────┐
        │                                 │
  templateType = 0                  templateType = 1
   (公司模板)                         (客户模板)
        │                                 │
        ↓                                 ↓
PendingSalesManagerApproval      PendingLegalReview
 (待销售经理审批)                  (待法务审核)
        │                                 │
        │ 批准                             │ 批准
        ↓                                 ↓
PendingSalesDirectorApproval    LegalReviewedPendingSalesManager
 (待销售总监审批)                  (法务已审核-待销售经理)
        │                                 │
        │                                 │ 批准
        │                                 ↓
        │                      LegalReviewedPendingSalesDirector
        │                       (法务已审核-待销售总监)
        │                                 │
        │ 批准                             │ 批准
        ↓                                 ↓
        └─────────────┬───────────────────┘
                      │
                      ↓
               PendingSeal
                (待盖章)
                      │
                      │ 盖章
                      ↓
                  Sealed
                (已完成)

        任何阶段拒绝
             ↓
          Rejected
          (已拒绝)
```

## 防篡改验证流程

```
┌─────────────────┐
│   发出合同PDF    │
│  (原始文件)      │
└────────┬────────┘
         │
         │ 客户签署
         ↓
┌─────────────────┐
│   客户返回PDF    │
│  (可能被修改)    │
└────────┬────────┘
         │
         │ 上传到系统
         ↓
┌─────────────────────────────────────┐
│         OCR Service                 │
│                                     │
│  ┌──────────────────────────────┐  │
│  │  1. ExtractTextFromPdfAsync() │  │
│  │     - 原始文件文本            │  │
│  │     - 返回文件文本            │  │
│  └──────────────────────────────┘  │
│                                     │
│  ┌──────────────────────────────┐  │
│  │  2. CompareContractsAsync()   │  │
│  │     - Levenshtein距离计算     │  │
│  │     - 相似度评分              │  │
│  │     - 差异检测                │  │
│  └──────────────────────────────┘  │
└────────┬────────────────────────────┘
         │
         ↓
┌─────────────────────────────────────┐
│      ComparisonResult               │
│  - isMatch: true/false              │
│  - similarityScore: 0.00-1.00       │
│  - differences: [...]               │
└─────────────────────────────────────┘
         │
         ├─ 相似度 > 95% ─→ 验证通过
         │
         └─ 相似度 ≤ 95% ─→ 验证失败
                              (可能被篡改)
```
